# RPG Recommendation System 🎮

Bem-vindo ao **RPG Recommendation System**! Este projeto foi criado para recomendar jogos de RPG com base no seu gosto pessoal. Responda a algumas perguntas simples e receba uma recomendação personalizada de um jogo que combina perfeitamente com você.

## 🚀 Como Rodar o Projeto

Siga os passos abaixo para rodar o projeto no seu computador:

### Pré-requisitos

- [.NET SDK](https://dotnet.microsoft.com/download) (versão 8.0 ou superior)
- Um editor de código (recomendamos [Visual Studio](https://visualstudio.microsoft.com/) ou [VS Code](https://code.visualstudio.com/))

### Passos para Executar

1. **Clone o repositório:** git clone https://github.com/pedroluceena/RpgRecommendation.git

2. **Navegue até a pasta do projeto:** cd RpgRecommendation

3. **Restaurar as dependências:** dotnet restore

4. **Execute o projeto:** dotnet run

5. **Acesse a aplicação: Abra o navegador e acesse:** http://localhost:5000

6. **Responda as perguntas:** Na página inicial, responda às perguntas para receber sua recomendação de RPG personalizada.

## 🛠️ Funcionalidades

Recomendação Personalizada: Com base nas suas respostas, o sistema recomenda um jogo de RPG que combina com seu estilo.

Interface Simples e Intuitiva: Fácil de usar, mesmo para quem não tem experiência com jogos.

Banco de Dados de Jogos: Um banco de dados com diversos jogos de RPG para garantir recomendações precisas.

## 📂 Estrutura do Projeto

**Pages/:** Contém as páginas da aplicação, incluindo a página de recomendação.

**Services/:** Lógica de negócio e serviços, como a recomendação de jogos.

**Models/:** Definição das entidades e do banco de dados.

**Program.cs:** Configuração e inicialização da aplicação.
